Sovereign AI OpenAPI 3.1 REST API & Client SDK Reference

OPENAPI 3.1 COMPATIBLE | REST SPECIFICATION

The Elesium inference server implements an OpenAPI 3.1.0 compatible endpoint layer. Standard OpenAI client libraries (Python, Node.js, Go) can connect by simply redirecting the base_url to the internal sovereign gateway.

POST /v1/chat/completions

Creates a model response for the given chat conversation. Supports streaming and deterministic JSON schema formatting.

Request Headers

Header Type Description
Authorization string Bearer token generated by your enterprise identity provider (IdP).
X-Elesium-Audit-Tenant string Immutable enterprise tenant identifier for SIEM log routing.

cURL Example

BASHTerminal
curl -X POST https://10.240.16.4:8443/v1/chat/completions   -H "Content-Type: application/json"   -H "Authorization: Bearer $ELESIUM_ENTERPRISE_KEY"   -H "X-Elesium-Audit-Tenant: IN-BFSI-01"   --cert /etc/ssl/certs/client.crt   --key /etc/ssl/private/client.key   --cacert /etc/ssl/certs/elesium_ca.crt   -d '{
    "model": "elesium-indic-sovereign-70b-fp8",
    "messages": [
      {"role": "user", "content": "Generate structured underwriting checklist."}
    ],
    "temperature": 0.0,
    "stream": false
  }'
