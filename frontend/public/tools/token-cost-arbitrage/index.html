1. Mathematical Formulation & Amortization Mechanics

The total cost of ownership (TCO) for foundation model inference diverges significantly between multi-tenant public APIs and dedicated private sovereign clusters. The model implements the following dual-cost formulation:

C_cloud = ((T_in * P_in + T_out * P_out) / 1,000,000) * 12
C_sovereign = C_hw_amortized + C_power_cooling + C_network_egress
Net_Annual_Savings = C_cloud - C_sovereign
Arbitrage_Ratio = (Net_Annual_Savings / C_cloud) * 100%
