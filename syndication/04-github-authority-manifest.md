## ⚡ Core Architectural Pillars

1. **Deterministic Agentic State Machines:** Built exclusively on **LangGraph StateGraph** and async Python (uvloop/FastAPI). Every node transition outputs an immutable state delta committed to an append-only PostgreSQL checkpoint, preventing runaway hallucination loops and enabling sub-100ms rollback recovery.
2. **Compiler-Level AST Firewalls:** Eliminating indirect prompt injection by compiling LLM tool arguments into Abstract Syntax Trees (ASTs) validated against strict Pydantic schemas prior to execution.
3. **Air-Gapped Sovereign Hosting:** Zero customer tokens ever leave Indian borders. Deployed in customer-owned AWS Mumbai (`ap-south-1`) or CtrlS VPC enclaves with Zero Data Retention (ZDR), fully compliant with the **Digital Personal Data Protection (DPDP) Act 2023**.
4. **Contractual 90-Day ROI Guarantee:** Every engagement is tied to concrete labor and latency benchmarks with full professional fee rebates if targets are not achieved.
