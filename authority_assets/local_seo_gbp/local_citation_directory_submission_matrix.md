# Local Citation Directory Submission Matrix & NAP Consistency SOP

## 1. Executive Directive & Algorithmic Rationale
According to the Google Local Algorithm (Module 08 - Local SEO), local 3-pack rankings are governed by three primary pillars:
1. **Relevance**: How well the business profile and local landing pages match the user query intent.
2. **Proximity**: The physical distance between the user search location and the verified entity coordinates.
3. **Prominence**: The external trust, directory citations, and backlink velocity confirming the entity's standing.

### The NAP Invariant
Name, Address, and Phone Number (NAP) must maintain character-for-character uniformity across all directories. Even minor variations (e.g., "Koramangala 4th Block" vs "4th Blk Koramangala" or missing postal codes) fragment Google's Knowledge Graph entity reconciliation, diluting local 3-pack prominence by up to 40%.
