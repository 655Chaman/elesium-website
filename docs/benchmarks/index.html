NVIDIA H100 SXM5 Cluster Latency & Throughput Benchmarks

Walker Direct-Answer Invariant

What empirical TTFT latency and throughput does Elesium achieve on NVIDIA H100 SXM5?

Audited benchmark telemetry across NVIDIA H100 80GB SXM5 clusters connected via 900 GB/s NVLink v4 confirms 121.4ms TTFT on 8x H100 SXM5 for Llama-3.3-70B FP8 (scaling to 1,840 tok/s batched) and 148ms TTFT / 124.5 tok/s on 2x H100 SXM5 for Elesium-Indic-70B FP8 Batch 1.

AUDITED PERFORMANCE TELEMETRY | NVIDIA H100 SXM5 CLUSTER

All benchmark measurements were conducted inside an air-gapped VPC located in Mumbai (ap-south-1) on bare-metal NVIDIA H100 80GB SXM5 instances connected via 900 GB/s bidirectional NVLink v4 across 100,000 continuous benchmark cycles: 121.4ms TTFT on 8x H100 SXM5 for Llama-3.3-70B FP8, and 148ms TTFT / 124.5 tok/s on 2x H100 SXM5 for Elesium-Indic-70B FP8 Batch 1.
