## 🛠️ PART 4: STEP-BY-STEP OPERATIONAL SPECIFICATIONS

### Step 1: On-Page Mathematical Density Tuning (Kyle Roof Protocol)
Every primary commercial URL must satisfy this exact anatomical checklist:
* **Page Title Tag:** `[Primary Keyword] | [Secondary Modifier] — [Brand]` (Under 60 chars).
* **H1 Tag:** Exactly 1 H1 tag containing the exact primary keyword anchor.
* **First 100 Words:** Include exact primary keyword, secondary intent, and geographical entity (`Bangalore, Karnataka, India`).
* **Last 100 Words:** Repeat primary keyword in conclusion + direct commercial CTA.
* **H2 Structure:** Every H2 must follow the pattern:
  `<h2>[Descriptive Keyword-Rich Heading]</h2>`
  `<p><strong>[40–50 Word Answer Capsule delivering immediate factual definition]</strong></p>`

### Step 2: Static DOM Pricing Hardening (Shaun Mitchell Protocol)
* Eradicate any `<details>`, `<accordion>`, or JavaScript toggle hiding prices.
* Render 3 distinct tiers with clear INR and USD pricing.
* Match `PriceSpecification` in JSON-LD character-for-character with visible text.

### Step 3: Schema.org Knowledge Graph Integration (Fountain Hills Protocol)
* Inject unified `@graph` into `<head>`:
  * `Organization` + `ProfessionalService` + `LocalBusiness`.
  * `sameAs` array linking all verified brand nodes (GoodFirms, Clutch, LinkedIn, GitHub, Wikidata Q11660).
  * `hasOfferCatalog` with exact pricing.
  * `FAQPage` with questions and answers matching on-page FAQs.

### Step 4: Video Mirror Hub & Transcript Rendering (Nestor Vasquez Protocol)
* Host videos at `/videos/:slug`.
* Embed responsive video container.
* Render full timestamped transcript in readable DOM.
* Add `VideoObject` schema with `hasPart` clip moments and full transcript string.

### Step 5: Parasite Syndication Pipeline (Craig Campbell Protocol)
* Run `python3 automation/link_builder.py --flagship-suite`.
* Generates 8 full Markdown whitepapers in `automation/syndications/<slug>/article_full.md`.
* Each article carries `canonical_url: https://elesium.online/...`.
* Publish via API or manual copy-paste to Dev.to and Hashnode.

### Step 6: Navboost Referral Engine (Chris Walker Protocol)
* Publish high-value LinkedIn posts educating the market without links.
* Close with: *"Search Google for 'Elesium AI automation agency India' and test the live terminal simulator."*
* Drives organic brand+keyword queries, 100% CTR on Elesium, and $>120\text{s}$ dwell time on page.
