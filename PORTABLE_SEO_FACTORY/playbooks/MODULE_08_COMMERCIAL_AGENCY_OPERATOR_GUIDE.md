### Detailed Day-by-Day Workflow

#### Phase 1: Days 1–2 — Intake & Entity Discovery
- **Action:** Drop `PORTABLE_SEO_FACTORY/` into the client repository or run `python3 setup_wizard.py`.
- **Inputs Extracted:**
  - Official Brand Name, Domain URL, and Canonical protocol.
  - Core industry, 3–7 hub categories, target personas (CTOs, VPs of Engineering, CROs).
  - Unspoken "It's Toasted" capabilities (e.g. *sub-1.5ms WAL checkpointing*, *private VPC air-gapped LLM deployment*).
  - Conversion route (`/waitlist`, `#demo`, `/contact`).
- **Output:** `project_config.json`.

#### Phase 2: Days 3–5 — Programmatic Generation
- **Action:** Run `python3 generator_engine.py --run-all`.
- **Outputs Generated:**
  - `keywords_queue.json` containing 50–250+ ultra-low competition BOFU keywords.
  - HTML/TSX page payloads applying `templates/bofu_landing_page.tmpl`.
  - Every page strictly between 350 and 500 words with micro-paragraphs (1–3 sentences).
  - Pre-injected with AEO Answer Capsule (40–50 words), Differentiator Table, 3-tier Pricing Grid, and Honest Trade-offs.

#### Phase 3: Days 6–8 — Compliance Audit
- **Action:** Run `python3 compliance_gatekeeper.py --audit-all`.
- **Verification Gates:**
  1. *Tri-Alignment:* Slug == `<title>` == Single `<h1>`.
  2. *Word Count:* Assert 350 <= words <= 500.
  3. *Moz Sweet Spot:* Moz score between 96 and 98 (assert NOT 100 to prevent over-optimization penalty).
  4. *Mobile Geometry:* Assert CTA button precedes any hero image/diagram in DOM.
  5. *Crawl Depth:* Assert all URLs reachable within <= 2 clicks from homepage.
  6. *Semantic SSG:* Self-referential canonical tag present on every URL.

#### Phase 4: Days 9–11 — Micro-SaaS Tool Deployment
- **Action:** Deploy the interactive simulator utilizing `templates/interactive_calculator_widget.tmpl`.
- **Dual-Mount Architecture:**
  - Standalone route: `/tools/roi-simulator`
  - Embed route: `/embed/roi-simulator`
  - Ensure watermark backlink is hardcoded: `Calculated via <a href="{{DOMAIN_URL}}">{{BRAND_NAME}}</a>`.

#### Phase 5: Days 12–13 — AEO / GEO Manifest & Schema Injection
- **Action:** Deploy `llms.txt`, `llms-full.txt`, and sector manifests to the `/public` root.
- Inject `templates/local_schema.tmpl` into the root layout and SSG pipeline:
  - Google Maps CID permanent URL linking.
  - `sameAs` array referencing Crunchbase, LinkedIn, GitHub, G2, Clutch, and Wikidata.
  - FAQPage schema mapping to all page accordion entities.

#### Phase 6: Day 14 — Live Broadcast & Handoff
- **Action:** Run `python3 portable_instant_indexer.py`.
- Push all generated URLs to `https://api.indexnow.org/indexnow`.
- Validate XML sitemaps at `/sitemap.xml` and submit directly to Google Search Console and Bing Webmaster Tools.
- Present client or partner agency with executive verification dashboard.

Our engine enforces Edward Sturm's 6 gates: every page is 350-500 words of verifiable engineering truth, backed by an interactive micro-SaaS calculator that forces 180+ second dwell times. #### Objection 2: "Why are your pages only 350 to 500 words? Shouldn't we write 3,000-word skyscraper articles?"
> **Response:** *"Skyscraper content is for Top-of-Funnel educational queries like 'what is supply chain management'.
