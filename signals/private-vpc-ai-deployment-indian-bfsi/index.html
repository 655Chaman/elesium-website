### 2.1 Deep Dive: Digital Personal Data Protection Act (DPDP Act 2023)

The DPDP Act establishes explicit requirements for autonomous AI pipelines processing data within India:

  • **Section 8(4) - Purpose Limitation and Erasure:** Personal data used to construct inference prompts or generate retrieval-augmented vectors must be purged instantly once the stated transaction finishes. Generic LLM providers that retain cached conversations violate this mandate.
  • **Data Principal Rights Integration:** Under Section 12, Data Principals retain the right to erase, correct, and update their records. If unstructured inputs enter model weights via direct fine-tuning, compliance becomes mathematically intractable. Elesium resolves this by locking model weights and storing knowledge strictly within an isolated vector substrate (PostgreSQL with `pgvector`), where individual records can be excised deterministically down to the exact embedding index.

### 3.1 Triad Architectural Components

#### 1. Data Access Agent (DAA) The DAA sits in a private subnet with direct interface endpoints (`AWS PrivateLink`) to Core Banking Systems (CBS) like Finacle or BaNCS. It isolates sensitive Personally Identifiable Information (PII). Using format-preserving encryption (FPE) and SHA-256 masking, the DAA sanitizes database payloads prior to orchestration. Primary keys, PAN details, and Aadhaar identifiers never reach the Inference Agent.

#### 2. Inference Agent (IA) The IA operates within an isolated compute cluster without internet access, running containerized instances of enterprise open-weights (e.g., Llama-3-70B-Instruct, DeepSeek-R1-Distill) via optimized inference runtime engines such as vLLM or TensorRT-LLM. Model execution runs under strict parameters ($Temperature = 0.0$, $Top\_P = 1.0$) with fixed seed initializations to eliminate probabilistic drift across reliable routing steps.

#### 3. Orchestration Agent (OA) The OA governs operational flow. Built on an explicit state machine, it intercepts all user intents, enforces role-based access control (RBAC), interacts with the vector retrieval substrate, and validates inference outputs against hardcoded business rules prior to downstream dispatch.

### 3.2 Network Topology & Attack Surface Hardening

The Multi-Agent Triad enforces strict infrastructural isolation:

  • **Zero Public Ingress:** No node inside the AI deployment boundary possesses a public IP address. All client communication must traverse an internal Application Load Balancer via dedicated corporate MPLS or AWS Direct Connect.
  • **Zero Outbound Internet:** Egress internet gateways (`nat-0.0.0.0/0`) are explicitly omitted from routing tables. Models cannot communicate with external endpoints, defeating prompt-based data exfiltration attacks.
  • **Mutual TLS (mTLS) Everywhere:** Inter-agent communication within the private VPC requires cryptographic authentication through x509 certificates generated by an enterprise-managed AWS Private Certificate Authority (PCA).
