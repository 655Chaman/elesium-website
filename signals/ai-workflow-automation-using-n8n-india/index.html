2. Production Architecture: Air-Gapped High-Availability n8n Cluster Topology

For mission-critical production workloads, n8n cannot be operated as a single monolithic Docker container. Elesium architects distributed, queue-mode topologies designed to handle high concurrency with zero message drop: ``` ┌────────────────────────────────────────────────────────────────────────┐ │ Enterprise Inbound Webhook Layer (FastAPI API Gateway / NGINX Proxy) │ └───────────────────────────────────┬────────────────────────────────────┘ │ mTLS / JWT Bearer Validation (sub-15ms) ▼ ┌────────────────────────────────────────────────────────────────────────┐ │ n8n Main Leader Node (Workflow Engine, State Orchestrator, UI & API) │ └───────────────────────────────────┬────────────────────────────────────┘ │ Job Dispatches via BullMQ Engine ▼ ┌────────────────────────────────────────────────────────────────────────┐ │ Redis 7.2 Cluster (Dedicated Task Queues & Pub/Sub Status Buses) │ └───────────┬───────────────────────┬───────────────────────┬────────────┘ │ │ │ ▼ ▼ ▼ ┌───────────────────────┐┌───────────────────────┐┌───────────────────────┐ │ n8n Worker Pod 01 ││ n8n Worker Pod 02 ││ n8n Worker Pod 03 │ │ (LLM & Embeddings) ││ (ERP / SAP Connector) ││ (Banking / Webhooks) │ └───────────┬───────────┘└───────────┬───────────┘└───────────┬───────────┘ │ │ │ └────────────────────────┼────────────────────────┘ │ temporary Execution & State Sync ▼ ┌────────────────────────────────────────────────────────────────────────┐ │ PostgreSQL 16 + pgvector Database (State History, Audit Logs, Vectors) │ └────────────────────────────────────────────────────────────────────────┘ ```

Under queue mode, the n8n main instance only acts as the orchestrator and scheduler. Heavy workflow tasks—including tokenizing documents, querying semantic pgvector indices, and invoking local private LLM endpoints (Ollama/vLLM)—are immediately offloaded to auto-scaling worker pods. If an ERP gateway or external banking API experiences transient throttling, BullMQ guarantees exponential backoff retries without freezing the primary workflow engine.

4. DPDP Act 2023 Statutory Compliance & Localized Cryptographic Audit Trails

Under Section 8(4) and Section 9 of India's Digital Personal Data Protection (DPDP) Act 2023, data fiduciaries face statutory penalties of up to ₹250 Crore for failing to institute reasonable security safeguards against personal data breaches. When consumer data traverses third-party low-code SaaS providers, enterprise legal teams lose control over log persistence, cross-border token replication, and third-party sub-processors.

Elesium's private n8n implementation embeds a dedicated **Cryptographic Audit Interceptor Node** into every workflow execution graph: 1. **temporary Payload Sanitization:** Personally Identifiable Information (Aadhaar numbers, PAN, mobile numbers, bank account details) is hashed using HMAC-SHA256 at the ingestion webhook boundary before entering downstream LLM prompt contexts. 2. **Immutable Append-Only Execution Trails:** Every state transition and node execution output is committed to an encrypted PostgreSQL ledger with zero-knowledge integrity proofs, ensuring an audit-proof paper trail for CERT-In and RBI statutory inspectors. 3. **Automated Right-to-Erasure Hooks:** Native n8n sub-workflows listen to Data Principal consent withdrawal events, automatically purging vector embeddings and user context records from pgvector within 24 hours of notification.
