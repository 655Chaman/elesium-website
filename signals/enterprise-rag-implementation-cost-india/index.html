2. Comprehensive Infrastructure Cost Breakdown (AWS Mumbai ap-south-1 vs Indian Cloud Providers)

Infrastructure expenditure in an enterprise RAG pipeline comprises four distinct compute and storage tiers: (1) Vector Database memory footprint, (2) Document Ingestion and Embedding compute, (3) Real-time LLM Inference GPU instances, and (4) Private networking and egress bandwidth within Indian borders.

### 2.1 Vector Database Memory Sizing & HNSW Index Overhead A standard misconception is that vector databases scale with disk storage. In high-concurrency production deployments, Hierarchical Navigable Small World (HNSW) vector graphs must reside entirely in volatile RAM to maintain sub-15ms nearest-neighbor retrieval latencies. The mathematical RAM allocation required for an enterprise document corpus is governed by: ``` M_RAM = N_docs * (D_dim * 4 bytes + M_neighbors * 8 bytes) * 1.25 (index buffer overhead) ``` For an enterprise corpus of 20,000,000 document chunks using 1536-dimensional embeddings (`text-embedding-3-large` or `bge-m3`) with an HNSW construction factor $M=32$: * Raw Vector Memory: 20M * 1,536 * 4 bytes = 122.88 GB RAM * HNSW Graph Connection Links: 20M * 32 * 8 bytes = 5.12 GB RAM * Operating Buffer: 128.0 GB * 1.25 = **160.0 GB Dedicated High-Speed RAM** Hosting this dedicated index on an **AWS RDS PostgreSQL (pgvector)** `db.r6g.4xlarge` instance (16 vCPUs, 128 GB RAM) or `db.r6g.8xlarge` (32 vCPUs, 256 GB RAM) in the Mumbai (`ap-south-1`) region costs approximately **₹1,84,000 to ₹3,68,000 per month** ($2,150 to $4,300/mo), excluding backup snapshots and Multi-AZ replication.

### 2.2 private GPU Inference Compute: Self-Hosted vLLM vs Cloud APIs For Indian BFSI and healthcare institutions bound by data localization mandates, sending customer queries to third-party US cloud APIs is legally untenable. Deploying fine-tuned 14B or 70B parameter models (e.g., Llama-3.3-70B or Qwen-2.5-72B quantized via AWQ/GPTQ) on sovereign compute requires: * **AWS Mumbai (`ap-south-1`) `g5.12xlarge`** (4x NVIDIA A10G 96GB VRAM): ~₹5,12,000/month on on-demand pricing, or ~₹3,35,000/month on 1-Year Reserved Instances. * **Indian private Cloud (Yotta / E2E Networks)** (NVIDIA H100 SXM5 80GB): ~₹2,85,000 to ₹4,20,000/month per node. * **Comparative API Token Burn:** An enterprise processing 50,000 daily queries averaging 3,500 input tokens (retrieved context) and 400 output tokens consumes 195 million tokens monthly, generating a variable monthly bill of **₹2,90,000 to ₹6,80,000** under third-party commercial APIs, without data sovereignty guarantees.

5. Hidden Financial Leaks & Regulatory Liabilities under India DPDP Act 2023

Beyond compute and talent, enterprise CFOs must account for regulatory and operational liabilities specific to India: 1. **DPDP Act 2023 Section 8(4) Statutory Penalties:** Fines up to **₹250 Crores** can be levied by the Data Protection Board of India for failures to implement reasonable security safeguards resulting in personal data exposure. Utilizing public third-party APIs where prompts are cached on foreign servers creates severe non-compliance exposure. 2. **Goods and Services Tax (GST) Input Mechanics:** Cloud infrastructure provisioned through AWS India (Amazon Internet Services Pvt Ltd) or local data centers attracts 18% GST. When structured correctly under an enterprise IT vendor contract like Elesium, the full 18% GST is eligible for Input Tax Credit (ITC), effectively reducing net infrastructure spend. 3. **Withholding Tax (TDS Section 194J):** Professional engineering advisory contracts are subject to 10% TDS (or 2% for specified technical services), which optimizes cash flow management compared to immediate cross-border credit card debits subject to 20% Tax Collected at Source (TCS) or Equalisation Levies.
